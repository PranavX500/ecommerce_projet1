Welcome to **Milestone 32**! 🌟  
In this milestone, we focused on integrating **Redux** to manage and access the user's email across all pages of our application.

---

## 🎯 Learning Goals

By the end of this milestone, you will:

- Understand how to use **Redux** to manage global state.
- Learn to **dispatch** actions to update the Redux store.
- Use **useSelector** to access Redux state from any page in the app.

---

## 🛠️ What We Did

### 🔐 Login Page

- Implemented the `dispatch` method to store the **user's email** in the Redux global state when the user logs in.

### 📄 All Other Pages

- Used the `useSelector` hook to **access the stored email** from the global state and display/use it as needed.

---

## 📚 Key Concepts Used

- **Redux Store**
- **Actions & Reducers**
- **Dispatching Actions**
- **useSelector Hook**

This milestone strengthened our understanding of **global state management** using Redux, an essential concept in large-scale React applications.
