## 🎯 Learning Goals

By the end of this milestone, we will:

- Understand how to use the **PayPal API**.
- Learn how to **integrate online payments** into our web application.

---

## 📝 Steps for Milestone 29

1. **Create a PayPal Account**
   - Go to the [PayPal Developer Dashboard](https://developer.paypal.com).
   - Log in and navigate to **Sandbox Accounts**.

2. **Get Sandbox Credentials**
   - Copy the **User ID** and **Client ID** from our sandbox account and save them securely.

3. **Update Order Confirmation Page**
   - Add **two payment options**:
     - Cash on Delivery (COD)
     - Online Payment (via PayPal)

4. **UI Enhancements**
   - Use **radio buttons** to toggle between COD and Online Payment.
   - When **Online Payment** is selected, display the **PayPal payment buttons**.

> ⚠️ In the next milestone, we’ll write the actual code to handle PayPal button logic and payment processing.
