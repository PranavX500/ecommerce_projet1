## 📚 Milestone Summary

In this milestone, we implemented the **Cancel Order** functionality in the `my-orders` page and created a backend endpoint to process order cancellations.

---

## ✅ Learning Goals

By the end of this milestone:

- Users can **cancel their placed orders**.
- Orders that are **already canceled** will not show the cancel button.
- You will understand how to update data conditionally and connect frontend actions with backend logic.

---

## 🧩 Features Implemented

- 🔘 Cancel button added to each order in `my-orders` page.
- ❌ Cancel button **hidden** for already canceled orders.
- 🔗 Backend endpoint to receive `order-id` and cancel the respective order.
- 📦 Order status updated to `canceled` and saved to the database.

---

## 🔧 Tech Stack

- **Frontend:** React, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (Mongoose)
- **Version Control:** Git + GitHub
