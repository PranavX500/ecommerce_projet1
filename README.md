📌 Overview
In this milestone, we have implemented a backend endpoint to retrieve all orders of a user based on their email. This helps in understanding how to fetch user-specific data efficiently.

🎯 Learning Goals
By completing this milestone, we have learned:

How to create an endpoint to fetch user orders.

How to retrieve a user's _id using their email.

How to fetch and return all orders linked to that user.

🛠️ Implementation Steps
Created an endpoint that accepts the user's email.

Fetched the user’s _id from the database using the provided email.

Retrieved all orders associated with that _id.

Sent the orders as a response in JSON format.
