In this milestone, we’ll build a frontend order confirmation page that shows ordered products, delivery address, total amount, and provides a button to place the order.

🎯 Learning Goals
By the end of this milestone, you will:

Build a frontend order confirmation page.

Display:

All products being ordered

The selected delivery address

The total value of the order

Add a "Place Order" button to confirm the purchase.

📝 Steps to Follow
Display Ordered Products
Show a list of all the products included in the order.

Show Selected Delivery Address
Display the delivery address chosen by the user.

Display Total Cart Value
Calculate and show the total price of all items in the cart.

Add "Place Order" Button
Include a button at the bottom of the page that users can click to place the order.

🧠 Why This is Important
This milestone helps you understand the core functionality of an e-commerce checkout system, where:

Users verify order details

Select or confirm delivery addresses

Finalize their purchase with a single click
