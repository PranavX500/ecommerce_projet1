Welcome to Milestone 14! 🌟

In this milestone, we will implement the delete functionality for products. We will add a Delete button in the frontend and create a backend endpoint to delete a product using its ID in MongoDB.

Learning Goals 🎯

By the end of this milestone, you will:

Understand how to write an API endpoint to delete a product from MongoDB.

Learn how to integrate the delete functionality with the frontend.

Steps for Milestone 14 📝

Backend: Write an endpoint to delete a product using its ID.

Frontend: Add a Delete button to each product card.

Integration: When the Delete button is clicked, send a request to the server to delete the corresponding product.
