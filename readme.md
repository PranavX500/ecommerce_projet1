👤 Milestone 20 - User Profile Page & Data Endpoint
Hey Kalvians! 👋

Welcome to Milestone 20! 🌟
In this milestone, we’ll build a Profile Page UI and implement a backend endpoint to fetch and display user data.

🎯 Learning Goals
By the end of this milestone, you will:

Create a backend endpoint to fetch user data using the user's email.

Build a frontend profile page to display the user's information.

Display the user's profile photo, name, email, and addresses.

📝 Steps to Follow
Create the Backend Endpoint

Build an API that returns all user data (based on the user's email).

Create the Frontend Profile Page

Display the profile photo, name, and email in one section.

In another section, display the list of addresses.

Add a button labeled "Add Address".

If no addresses exist, display the message: "No address found".

🧠 Why This is Important
This milestone will help you understand how to:

Build a dynamic user profile page.

Fetch and render user-specific data.

Handle conditional UI rendering based on data availability.
