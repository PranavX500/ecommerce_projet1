Product Schema 🛒

The product schema defines the structure of product data, including:

Name

Description

Price

Image URL

Schema Requirements:

Ensure each field has proper validation.

Required fields should be explicitly marked.

Use the correct data types for each field.

Endpoint Creation 🔗

We will build a POST endpoint that:

Receives product data.

Validates the incoming data.

Saves the product details to MongoDB.

Why Validation? ✅

Validation ensures that:

Only valid data is stored in the database.

Data integrity is maintained.

Potential errors are minimized.
