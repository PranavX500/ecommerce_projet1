Why Create a Product Form? 🛍️

This form will allow users to input all product details.

The entered details will be saved in a database and displayed on the products homepage (created in the previous milestone).

Steps for Milestone 9 📝

1️⃣ Create the Product Form

Design a form that includes fields for:

Product Name

Description

Price

Category

Multiple Product Images (Image Upload Feature)

2️⃣ Implement Multiple Image Upload Feature

Ensure the form allows users to upload multiple images.

Validate the image file types and sizes.

3️⃣ Experiment & Enhance 🚀

Feel free to add more advanced features, such as:

Admin Access: Only admins can upload products.

Shop Profile: A user with a shop profile can upload products.
