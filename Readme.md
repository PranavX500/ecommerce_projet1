Welcome to **Milestone 35!** 🌟  
In this final milestone, we'll deploy both our frontend and backend, and make our project live for the world to see!

---

## 🎯 Learning Goals

By the end of this milestone, we will:

- Learn how to deploy our **frontend** using a deployment service.
- Learn how to deploy our **backend** using a deployment service.
- Integrate both to create a **fully working live website**.

---

## 📝 Steps to Complete

1. **Deploy Backend**
   - Use any deployment service like Render, Railway, or Cyclic to deploy our backend.
   - Copy the deployment URL after successful deployment.

2. **Update Frontend**
   - Replace all `localhost` URLs in our frontend code with the **deployed backend URL**.

3. **Deploy Frontend**
   - Use services like Netlify, Vercel, or Firebase Hosting to deploy our frontend.
   - Ensure the site is accessible using the live URL.

4. **Test Everything**
   - Make sure our website is working correctly with both backend and frontend in sync.
