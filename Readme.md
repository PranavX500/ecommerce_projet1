Welcome to Milestone 19! 🌟
In this milestone, we’ll focus on building a Cart Page UI and implementing backend endpoints to manage product quantity inside the cart.

🎯 Learning Goals
By the end of this milestone, you will be able to:

Build a cart page UI that displays products in the cart (using the endpoint from Milestone 18).

Add + and - buttons to update the quantity of each product.

Create backend endpoints to handle increasing and decreasing the product quantity in the cart.

📝 Steps to Follow
Create the Cart Frontend Page
Display the list of products in the user's cart using the existing API from Milestone 18.

Add Quantity Controls
For each product, add + and - buttons to update the quantity dynamically.

Build Backend Endpoints
Write two endpoints:

POST /cart/increase/:productId

POST /cart/decrease/:productId
These should update the product quantity accordingly.
